# DD8-BOSS-
SG-8 PRO Digital Delay ek offline digital delay aur vocal echo app hai jisme Live Mic, File Echo, Stereo Recording, aur WAV file save karne ka option milta hai. Isme E.LEVEL, F.BACK, D.TIME knobs, TAP tempo, HOLD, PING-PONG, aur multiple delay modes diye gaye hain.  Developer: _its_sameer_95_ (Sameer Graphics)
